Maturity

当前成熟度

按“当前证据”评估，而不是按目标能力评估。

领域状态说明
编译核心可用pages / components / subPackages、WXML/WXSS/WXS、manifest、service bundle、图片内联。
双线程 runtime可用页面栈、导航、setData、事件、组件、storage、system info、diagnostics。
内置组件部分18 个常用组件；示例所需语义可用，完整属性/事件仍缺。
API窄storage、导航、system、toast、animation、canvas、selector query；无网络/媒体/账号等。
生命周期部分基础页面/组件生命周期；tabBar、下拉刷新、触底、分享尚未覆盖。
样式系统核心可用class/tag 作用域；styleIsolation 等组件配置语义仍待补齐。
Devtool运行时级状态、诊断、元素树、控制；不是完整微信开发者工具。
性能 / 稳定未量化无启动、首屏、setData、内存、长时运行基准。

Known gaps

主要缺口

API

宿主 API 面很窄

缺 request、异步 storage、reLaunch/redirectTo/switchTab、showModal/loading、登录、媒体、文件、位置、WebSocket、IntersectionObserver。

components

组件语义不完整

缺 textarea/picker/form/navigator/video/audio/rich-text/map/movable-view 等；已有组件的 open-type、focus、confirm、颜色尺寸等属性也未完整覆盖。

pages

页面能力有限

无 tabBar、下拉刷新、触底、页面滚动事件、分享；子包只验证直接启动，未覆盖按需加载；pageLifetimes 仍是近似实现。

styles

隔离模式未完整

class/tag 作用域已解决，但 styleIsolation、app.wxss 到组件内部的边界、:host 组合和优先级矩阵还没有系统验收。

canvas

可交互 canvas 未完成

当前是“离屏绘制 → PNG 帧 → render drawImage”；没有 canvas 触摸事件、requestAnimationFrame、2D API 完整语义。

animation

动画是最终态映射

animation 数据被编译为 CSS transform/transition；多 step 时序和事件回调还未还原。

Next

下一阶段优先级

先把“真实小程序能跑”变成“常见小程序能跑”，再做性能和形态扩展。

P0

扩 API host

request、异步 storage、导航变体、modal/loading、系统信息异步版；把 unsupported API 从“静默失败”变成明确诊断。

P0

补常用组件

按真实使用频率补 textarea、picker、form、navigator，并把已有组件的属性/事件语义补全。

P1

页面能力

tabBar、下拉刷新、触底、页面滚动、分享、子包按需加载、页面栈恢复。

P1

生命周期与样式语义

Behavior mixin、pageLifetimes、组件 styleIsolation、app.wxss 作用边界。

P2

性能基线

启动耗时、首屏、setData 批量/差量、导航耗时、大列表内存、长时运行。

Invariants

架构不变量

核心不依赖工具/应用

packages/* 只能依赖核心包；manifest 契约独立，runtime 不再依赖 CLI。

一个 manifest 契约

compiler、runtime、host、devtool 都消费 @tiny/manifest；不要复制产物类型。

生成物不入库

宿主产物、组件 ProcGen、devtool static 都由构建生成；仓库只保留源码和测试 fixture。

验收必须真实

核心链路用真实双线程 + 浏览器操作验证；不接受只靠 mock 的“通过”。
