把小程序源码
编译成双线程运行时

Tiny 是一个基于 glass-easel 的小程序引擎实现。编译器产出 manifest 与线程产物， runtime 用 service / render 双 iframe 运行小程序，bridge 负责版本化消息，devtool 负责观察与控制。

Runtime skeleton

两个线程，一条桥

service 拥有逻辑和 API，render 拥有 glass-easel 组件树；host 只做编排与转发。

service thread

逻辑与 API

  • App / Page / Component 注册与生命周期
  • 页面栈、路由、setData patch
  • wx API host、storage、系统信息
  • canvas 离屏绘制与帧快照
  • 动画数据生成 CSS transform
render thread

组件树与 DOM

  • glass-easel 组件定义与 DOM backend
  • 页面挂载、样式作用域、tag 隔离
  • 事件派发、dataset、元素树导出
  • 内置组件 AOT 模板（无运行时 WXML 解析）
  • canvas 帧绘制到可见页面
协议是显式边界

消息 envelope 带 version、kind、domain、source/target、pageId 和 replyTo；payload 必须 JSON-safe。transport 可以替换为 MessagePort 或内存通道。

真实示例 app

todos、add-todo、ECharts bar 页、子包页面、组件插槽与自定义组件。

Taro 3 兼容

webpackJsonp、外部 WXS、递归模板、循环 usingComponents、页面生命周期方法都能运行。

样式作用域

class 与 tag 选择器都按页面/组件隔离；组件内部 WXSS 不再泄漏到全局。

Canvas 镜像

service 侧绘制、50ms 节流快照、render 侧 drawImage；ECharts 页面能看到真实图表。

内置组件 AOT

构建期把 18 个内置组件模板编译成 ProcGen，启动时只选择模板。

可观测性

结构化诊断贯穿 service/render/host，bootstrap、page-ready 失败都带 stack。

Quick start

从零跑起来

需要 Node.js 22+ 和 pnpm 9（仓库已声明 packageManager）。

# 安装依赖
pnpm install

# 完整验收：构建、单测、四段浏览器流程
pnpm accept:glass-easel

# 本地起测试宿主
pnpm dev:glass-easel

# 调试器
pnpm dev:devtool
